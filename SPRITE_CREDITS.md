# Sprite and Asset Credits

This document tracks all freely licensed 2D sprites and assets used in the 3D Social Media Game.

## Sprites Used

As the game develops and sprites are added, they will be documented here with:
- Asset name
- Source URL
- License type (CC0, CC-BY, CC-BY-SA, etc.)
- Original author/creator
- Any modifications made

### Format

```
### Asset Name
- **Source**: [URL to asset]
- **License**: [License type]
- **Author**: [Original creator]
- **Modifications**: [Any changes made, or "None"]
```

## Adding New Sprites

When adding new sprites to the game:

1. Ensure the sprite is freely licensed (CC0, CC-BY, CC-BY-SA, etc.)
2. Download and store the sprite in `assets/sprites/`
3. Add an entry to this file with full attribution
4. Update any relevant code that references the sprite

## Common Sprite Sources

- **OpenGameArt.org** - Open source game art
- **Kenney.nl** - Free game assets
- **Itch.io** - Indie game assets (check individual licenses)
- **Creative Commons Search** - Licensed creative works
- **Pixabay** - Free stock images
- **Pexels** - Free stock images
- **Unsplash** - Free stock images
